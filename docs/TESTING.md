# 수동 검증 절차

1. 이전 테스트 서버를 종료합니다.
2. `python server.py`를 실행하고 첫 줄에 `STEP UI-SYNC-1.0`이 표시되는지 확인합니다.
3. 클라이언트를 완전히 종료한 뒤 다시 접속합니다.
4. 월드 진입 후 약 8초의 클라이언트 준비 시간이 지난 뒤 이동되는지 확인합니다.
5. 캐릭터 오른쪽 약 3칸에 사나운 멧돼지가 지연 없이 표시되는지 확인합니다.
6. 몬스터 공격 시 플레이어 공격 모션과 몬스터 피격 모션이 재생되는지 확인합니다.
7. 서버 로그에서 `hp=50->...` 형태로 HP가 감소하는지 확인합니다.
8. HP가 0이 되면 `MONSTER-DEATH-ACTION`과 `[REWARD]`가 출력되는지 확인합니다.
9. 약 1.5초 뒤 멧돼지 시체가 사라지고, 사망 시점부터 약 10초 뒤 다시 나타나는지 확인합니다.
10. 게임 채팅에 `.status`와 `.inventory`를 입력해 응답이 표시되는지 확인합니다.
11. 캐릭터 정보 UI에서 레벨·경험치·STR·DEX 값이 `.status` 결과와 같은지 확인합니다.
12. 인벤토리 UI에서 식량 주머니 아이콘과 수량이 표시되는지 확인합니다.

경험치와 드롭은 `data/runtime.sqlite`에 저장되며 드롭은 현재 자동 획득됩니다. 채팅 명령은 UI 동기화 결과를 비교하는 관리자용 보조 기능으로 유지됩니다.

오류를 제보할 때는 다음을 함께 기록합니다.

- 실행한 커밋 ID
- 서버 콘솔의 마지막 30줄
- `C->S LIVE`와 `S->C MOVE-ACK` 앞에 표시된 경과시간
- 클라이언트에서 보인 현상
- 접속, 이동, 생성, 공격 중 실패한 단계
