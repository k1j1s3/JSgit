# LineageR Local Server

개인 환경에서 프로토콜 호환성을 연구하기 위한 Python 기반 로컬 서버 프로토타입입니다.

현재 최신 구현은 월드 진입, 이동 응답, 채팅/상점 요청 처리와 Core Server v1 전투 상태를 지원합니다. 공격 시 무기·능력치·몬스터 방어력을 사용해 데미지를 계산하고 HP, 사망, 경험치, 드롭 및 캐릭터 위치를 로컬 SQLite에 저장합니다.

## 현재 상태

- 완료: 게스트 세션 기반 접속 및 월드 초기화
- 완료: 월드 진입 직후 이동 요청 처리
- 완료: 데이터 기반 몬스터 생성
- 완료: 플레이어 공격 및 몬스터 피격 모션
- 완료: 무기·STR·DEX·레벨·AC 기반 전투 계산
- 완료: HP 감소, 사망 판정 및 사망 액션
- 완료: 경험치, 레벨업 기반 구조 및 드롭 적립
- 완료: 캐릭터 위치·경험치·인벤토리 영속 저장
- 완료: 상태·전투·콘텐츠·저장 계층 모듈화
- 예정: 경험치 UI와 바닥 드롭의 클라이언트 패킷 연결

자세한 진행 기록은 [ROADMAP.md](ROADMAP.md)와 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 실행 준비

Python 3.10 이상을 권장합니다. 외부 Python 패키지는 필요하지 않습니다.

서버는 `data/lineager_server_data.sqlite`를 읽습니다. 이 데이터베이스는 캡처 데이터 및 배포 권한 문제를 피하기 위해 Git에서 제외되어 있습니다. 기존 로컬 파일을 다음 위치에 복사하세요.

```text
data/lineager_server_data.sqlite
```

## 실행

```powershell
python server.py
```

기본 TCP 포트는 `7867`입니다. 실행 전 같은 포트를 사용하는 이전 테스트 서버를 종료하세요.

## 디렉터리

```text
server.py          최신 로컬 서버
core/              상태·전투·콘텐츠·저장 도메인
config/            서버 및 전투 기본 설정
tests/             자동 단위·통합 테스트
tools/             패킷 캡처·복호화·진단 도구
docs/              분석 내용과 수동 검증 절차
data/              로컬 전용 데이터베이스 위치
archive/           이전 단계 코드(필요 시 보관)
```

## 주의

이 저장소는 개인 소유 환경의 상호운용성 연구와 로컬 테스트를 위한 것입니다. 원본 게임 APK, 인증 정보, 개인 세션 로그, 제3자 서버 데이터는 커밋하지 마세요.

## 자동 테스트

```powershell
python -m unittest discover -v
```

현재 착용 장비 패킷은 아직 확인되지 않았으므로 `config/server.json`의 기본 무기와 능력치를 사용합니다. 클라이언트 장비 상태 패킷이 확인되면 같은 전투 엔진에 연결할 수 있습니다.
