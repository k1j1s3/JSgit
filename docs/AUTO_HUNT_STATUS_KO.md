# LDPlayer 자동사냥 운영 현황

최종 갱신: 2026-08-21

## 목적과 범위

두 LDPlayer 캐릭터가 평상시 계속 자동사냥하도록 유지하고, PK 피격이나 저체력
상황에서 생존 귀환과 마을 정비를 수행한 뒤 사냥터로 복귀한다. 화면은
1280×720을 전제로 하며 ADB 화면 캡처와 입력만 사용한다.

## 대상 장치

| 역할 | ADB 장치 | 상태 |
|---|---|---|
| 메인 LDPlayer | `emulator-5554` | 실제 조작 활성화 |
| LDPlayer-1 | `emulator-5556` | 실제 조작 활성화 |

각 장치는 별도 로그와 축순 교대 상태를 사용한다.

- 로그: `data/auto-hunt/emulator-5554.log`, `emulator-5556.log`
- 교대 상태: `data/auto-hunt/hunting-route-DEVICE.json`
- 피격 증거 화면: `data/bot-evidence/`

위 런타임 파일과 화면 캡처는 Git에서 제외한다.

## 현재 복구 흐름

1. PK 전용 붉은 표시 또는 저체력을 감지한다.
2. 실제 우측 메뉴 패널이 열렸을 때만 닫는다.
3. 귀환 주문서를 누른 직후 AUTO를 해제한다.
4. 귀환 마을과 관계없이 지도 즐겨찾기를 연다.
5. 다섯 번째 `26. 기란 마을`로 이동한다.
6. 기란마을 이름 화면을 검증한다.
7. `통합 창고지기 노딤`으로 이동한다.
8. `자동 보관`으로 대상을 불러온 후 `모두 맡기기`를 누른다.
9. `잡화상 메이어`로 이동한다.
10. `주홍 물약`을 선택하고 `Max 49.9%`로 설정한 후 구매한다.
11. 축복받은 순간이동 주문서의 첫째·둘째 저장 장소를 번갈아 선택한다.
12. 오른쪽 이동 화살표로 텔레포트하고 AUTO를 다시 켠다.

축순 순서는 장치별로 저장되므로 프로그램을 재시작해도 유지된다. 메인의 두
장소는 `산적중`, `02. 메마른 사막`이며 LDPlayer-1은 `산적3`, `개미6`이다.

## 현재 생존 판정

- 강한 PK 전용 붉은 표시: 2회 연속 감지 시 귀환
- HP 15% 이하: 한 번 감지 시 귀환
- HP 25% 이하: 2회 연속 감지 시 귀환
- Safety Zone에서는 일반 피격 판정을 억제

실제 화면 캡처 간격은 환경에 따라 약 1.3~1.5초다. 한 번에 큰 피해를 받고
2초 안에 사망하는 상황을 완전히 보장하지는 못한다.

## 실행과 종료

프로젝트 루트의 PowerShell에서 실행한다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\auto-hunt-start.ps1
```

기본적으로 두 장치를 함께 시작한다. 실행 중이라는 오류가 나오면 먼저 종료한다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\auto-hunt-stop.ps1
```

설정은 `config/auto_hunt.json`, 실행 코드는
`tools/ldplayer_auto_hunt.py`에 있다.

## 필수 화면 전제

- 두 LDPlayer 해상도는 1280×720이어야 한다.
- 귀환 주문서는 오른쪽 끝 단축키에 있어야 한다.
- 축복받은 순간이동 주문서는 오른쪽 끝에서 다섯 번째 단축키에 있어야 한다.
- 지도 즐겨찾기는 정확히 5개이고 기란마을이 다섯 번째여야 한다.
- 축순의 첫째·둘째 저장 장소는 실제 사냥터여야 한다.
- 기란 NPC 목록의 창고지기와 잡화상 순서를 임의로 바꾸지 않는다.

이 전제가 바뀌면 실제 조작을 멈추고 좌표를 다시 검증해야 한다.

## 안전장치와 알려진 제약

- 창고와 잡화상 화면이 기준과 다르면 맡기기·구매·사냥터 이동을 중단한다.
- 기란마을 도착 화면이 검증되지 않으면 NPC 클릭을 중단한다.
- 빨간 알림점만으로 우측 메뉴를 닫지 않는다. 넓은 남색 패널이 실제로 열렸을
  때만 X를 누른다.
- 화면 검증 실패 후 프로그램은 임의의 후속 클릭을 하지 않으므로 마을에서
  멈출 수 있다. 이때 장치 로그의 마지막 `ERROR`를 확인한다.
- 월드보스와 일일 퀘스트 자동 실행은 현재 기본 비활성화 상태다.

## 테스트

```powershell
python -m unittest tests.test_auto_hunt
```

현재 자동사냥 회귀 테스트는 38개다. 설정을 바꿀 때는 테스트 후 두 감시기를
재시작해야 실행 중 프로세스가 새 설정을 읽는다.

## 주요 변경 이력

- PK 및 저체력 귀환과 즉시 AUTO 해제
- 기란마을 즐겨찾기 고정 경로
- 창고 자동 보관 후 모두 맡기기
- 주홍 물약 Max 49.9% 직접 구매
- 축순 두 장소 장치별 교대 및 상태 저장
- 두 LDPlayer 동시 감시
- 우측 메뉴 알림점 오인식 방지
