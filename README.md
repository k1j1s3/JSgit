# LineageR Local Server

> 프로젝트 방향 전환: 모바일 호환성 연구는 보존 상태이며, 현재 주 개발 경로는 공개 GPL-2.0 `l1j-en/classic` 기반 리니지 1 PC 로컬 서버입니다. 구축 결과와 실행법은 [L1J_SETUP_KO.md](docs/L1J_SETUP_KO.md)를 참고하세요.

개인 환경에서 프로토콜 호환성을 연구하기 위한 Python 기반 로컬 서버 프로토타입입니다.

현재 최신 구현은 Core Server, World/Rewards, UI Sync, Equipment Effects와 Player Survival & Defense v1을 지원합니다. 플레이어와 몬스터의 상호 공격, 장비 AC 기반 피해 감소, HP 저장, 자동 부활까지 서버 상태와 캐릭터 UI에 동기화됩니다.

## 실행 준비

Python 3.10 이상을 권장합니다. 외부 Python 패키지는 필요하지 않습니다.

서버는 `data/lineager_server_data.sqlite`를 읽습니다. 이 데이터베이스는 캡처 데이터 및 배포 권한 문제를 피하기 위해 Git에서 제외되어 있습니다. 기존 로컬 파일을 다음 위치에 복사하세요.

```text
data/lineager_server_data.sqlite
```

## 실행

```powershell
python server.py
```

기본 TCP 포트는 `7867`입니다. 실행 전 같은 포트를 사용하는 이전 테스트 서버를 종료하세요.

## 디렉터리

```text
server.py          최신 로컬 서버
core/              상태·전투·콘텐츠·저장 도메인
config/            서버 및 전투 기본 설정
tests/             자동 단위·통합 테스트
tools/             패킷 캡처·복호화·진단 도구
docs/              분석 내용과 수동 검증 절차
data/              로컬 전용 데이터베이스 위치
archive/           이전 단계 코드(필요 시 보관)
```

## 주의

이 저장소는 개인 소유 환경의 상호운용성 연구와 로컬 테스트를 위한 것입니다. 원본 게임 APK, 인증 정보, 개인 세션 로그, 제3자 서버 데이터는 커밋하지 마세요.

## 자동 테스트

```powershell
python -m unittest discover -v
```

LDPlayer가 실행 중이고 로컬 서버가 켜져 있으면 실제 앱 월드 진입과 인벤토리 화면을 자동 확인할 수 있습니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools\ldplayer_smoke_test.ps1
```

화면 아이템 터치 패킷으로 무기와 방어구를 장착·해제할 수 있으며 채팅 명령으로도 서버 장비·소모품 기능을 검증할 수 있습니다. UI에는 서버가 실제 계산에 사용하는 값이 표시됩니다.

## 게임 내 명령

게임 채팅에 다음 명령을 입력할 수 있습니다.

- `.status`: 레벨, 경험치, STR, DEX, 적용 무기 확인
- `.inventory` 또는 `.inv`: 서버에 저장된 자동 획득 아이템 확인
- `.item ID`: 강화 수치를 포함한 무기 공격력 확인
- `.equip ID`: 인벤토리에 있는 무기 장착
- `.unequip`: 현재 무기 해제
- `.equipment` 또는 `.gear`: 서버에 저장된 방어구 장착 슬롯 확인
- `.drops`: 현재 서버 바닥 드롭 객체와 위치 확인
- `.pickup OBJ`: 해당 바닥 객체를 거리·소유권 검사 후 습득
- `.hunt`: 현재 월드에 독립 상태의 멧돼지 6마리 사냥 구역 생성
- `.home`: 사냥 구역의 몬스터 객체를 모두 제거
- `.use ID`: 설정된 소모품 사용
- `.help`: 명령 목록 확인

사망한 몬스터는 기본 1.5초 후 제거되고 10초 후 다시 생성됩니다. 시간은 `config/server.json`에서 변경할 수 있습니다.

현재 지도 UI는 열리고 목적지 선택도 가능하지만 다른 지형의 원본 월드 초기화 패킷은 아직 없습니다. 실제 지형 전환 전까지 `.hunt`를 사용하면 시작 지형 안에서 다중 몬스터 전투·드롭·리스폰을 시험할 수 있습니다.
