# 수동 검증 절차

1. 이전 테스트 서버를 종료합니다.
2. `python server.py`를 실행하고 첫 줄에 `STEP 10F`가 표시되는지 확인합니다.
3. 클라이언트를 완전히 종료한 뒤 다시 접속합니다.
4. 월드 진입 후 약 8초의 클라이언트 준비 시간이 지난 뒤 이동되는지 확인합니다.
5. 캐릭터 오른쪽 약 3칸에 사나운 멧돼지가 지연 없이 표시되는지 확인합니다.
6. 몬스터 공격 시 플레이어 공격 모션과 몬스터 피격 모션이 모두 재생되는지 확인합니다.

현재 HP 감소와 사망은 구현되지 않았으므로 몬스터가 죽지 않는 것이 정상입니다.

오류를 제보할 때는 다음을 함께 기록합니다.

- 실행한 커밋 ID
- 서버 콘솔의 마지막 30줄
- `C->S LIVE`와 `S->C MOVE-ACK` 앞에 표시된 경과시간
- 클라이언트에서 보인 현상
- 접속, 이동, 생성, 공격 중 실패한 단계
